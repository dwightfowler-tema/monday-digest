[link](https://github.blog/changelog/2026-11-17-github-copilot-fusion-updates-more-availability-benchmarks-and-models)

Check any scheduled Claude Code task you rely on. The same release also adds a `Code Mode` default-on change and a trust-dialog warning about hooks. [link](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md)
