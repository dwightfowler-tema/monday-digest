## Changes how you work
- **GitHub Copilot:** "Copilot Fusion" is now generally available. Instead of picking a model per task, you pick Fusion plus an effort level (Standard, High, Max) and Copilot chooses and combines models for you. It is in VS Code, the Copilot app, Copilot CLI and JetBrains. GitHub says (its own benchmark claim) Fusion Max scored within two points of Claude Code with Opus 5.5 Max at about half the cost per task. Admins can restrict which models it uses or make it the default. [link](https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion)
- **GitHub Copilot:** The Copilot desktop app gained "Projects" (one workspace where Copilot runs several agents across repositories and other material, in public preview) and "computer use" (Copilot clicks and types in desktop apps for you, public preview on macOS and Windows, asks approval first). [link](https://github.blog/changelog/2026-10-28-github-copilot-app-universe-releases)
- **GitHub Copilot:** A new security extension for the Copilot app (public preview) lists your repository's code-scanning alerts (automated security findings) and lets you ask Copilot to explain or fix them locally, plus run `/security-review` on your current changes. Install: `copilot plugin install github-security@awesome-copilot`. [link](https://github.blog/changelog/2026-10-28-security-extension-for-the-github-copilot-app)
- **Claude Code changelog:** Version 2.1.316 deprecates fast mode (the faster-output setting) for Opus 4.8 as of Oct 30, 2026; it is removed Nov 30, 2026 and requests will then error. Migrate to Opus 5.5 to keep the speedup. It also adds `CLAUDE_CODE_SUBAGENT_EFFORT` to set the effort level helper agents run at. [link](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md)
- **Forward Future (essay):** The team argues the old prompting tricks ("act as an expert", "think step by step") no longer help much with current models and that over-long prompts are now a waste of time. This is the authors' opinion from an internal poll, not a measured result. Worth trying shorter prompts this week. [link](https://forwardfuture.com/newsletter/originals/does-prompting-still-matter-the-new-rules-for-getting-what-you-want-from-ai)
