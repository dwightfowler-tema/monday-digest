## Changes how you work
- **Claude Code changelog (2.1.323 and 2.1.325):** Several permission defaults changed. Sandboxed shell commands now follow the normal permission flow unless you set `sandbox.autoAllowBashIfSandboxed: true`. Scheduled tasks and `/loop` now ask before running a skill that declares `allowed-tools` or hooks (add `Skill(name)` to `permissions.allow` to run it unattended). A saved "Always allow" in Desktop, IDE and SDK hosts is now offered only when it would allow that command again, so a scheduled task that relied on one can now wait for you. Worth checking if you run unattended jobs like this digest. [link](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md)
- **Claude Code changelog (2.1.323):** Added "Code Mode", an experimental opt-in where Claude writes JavaScript to call its tools, instead of calling them one at a time. [link](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md)
- **GitHub Copilot:** Claude Fable 5.2 is generally available in Copilot (Pro+, Max, Business, Enterprise). Admins must switch on its policy; it is off by default and it requires data retention by Anthropic (zero data retention only for approved enterprises, time-limited to the end of the year). [link](https://github.blog/changelog/2026-11-09-claude-fable-5-2-in-github-copilot)
- **GitHub Copilot:** Gemini 4 Carbon (Nov 10) and Gemini 4 Hydrogen (Nov 13) are now selectable in Copilot's model picker; admins can manage them in model policy. [Carbon](https://github.blog/changelog/2026-11-10-gemini-4-carbon-in-github-copilot) · [Hydrogen](https://github.blog/changelog/2026-11-13-gemini-4-hydrogen-in-github-copilot)
- **GitHub Copilot:** On December 14, 2026, Copilot will retire Claude Fable 5, Claude Haiku 4.5 (still available to individual annual-plan subscribers), Gemini 3.8 Flash, Gemini 4 Argon, Grok 4.6 and Kimi K3. Update any workflow that names them; suggested replacements include Claude Fable 5.2 and Claude Haiku 5.5. [link](https://github.blog/changelog/2026-11-13-upcoming-deprecation-of-selected-github-copilot-models-in-december)
- **GitHub Copilot:** The GitHub Copilot app can now sign in to GitHub Enterprise Server (a company's self-hosted GitHub) from app 1.2.0; cloud sessions are not available there. [link](https://github.blog/changelog/2026-11-13-github-enterprise-server-support-in-the-github-copilot-app)
