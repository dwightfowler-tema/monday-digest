## Changes how you work
- **Claude Code changelog:** Versions 2.1.317 to 2.1.319 add a setting `permissions.denyInsteadOfPrompting` (a tool call that would wait for your permission is refused and the turn carries on, useful for unattended runs), a `/claude-api latency-optimize` command, and a check that asks before a web or shell tool call sends your account email address to the network. Also fixed: `claude -p` now exits with an error code when auto mode refuses actions. [link](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md)
- **GitHub Copilot:** Copilot is now in public preview inside Xcode's built-in coding assistant and in JetBrains Air, and the Nov 2 weekly roundup also lists pull-request, settings and agent-session updates. [Xcode](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant) · [weekly roundup](https://github.blog/changelog/2026-11-06-github-copilot-weekly-releases-november-2)
- **GitHub Copilot:** Copilot code review settings can now be managed through the REST and GraphQL APIs (programs talking to GitHub), from enterprise policy down to single repositories. [link](https://github.blog/changelog/2026-11-06-copilot-code-review-api-management-and-review-overview-updates)
- **GitHub Copilot:** `@GitHub` in Slack and Teams is generally available: you can investigate bugs, create issues, make changes and open pull requests from a chat conversation. [link](https://github.blog/changelog/2026-11-06-github-copilot-in-slack-and-teams-is-generally-available)
- **Simon Willison:** Technique: when coding agents open pull requests for you, hide their long, sloppy descriptions inside an HTML `<details><summary>` block (a collapsible section). [link](https://simonwillison.net/2026/Nov/9/details-summary/)
