## Changes how you work
- **GitHub Copilot:** OpenAI's GPT-6.2 Astra and Sol models are now in Copilot's model picker (for Pro+, Max, Business and Enterprise plans). GitHub says both catch more real problems in code review than the earlier GPT-6 models. [link](https://github.blog/changelog/2026-11-17-openais-gpt-6-2-astra-and-gpt-6-2-sol-now-available)
- **GitHub Copilot:** Gemini 4 Neon, a Google model, is now in Copilot. Google says it costs less per task than Gemini 4 Carbon. [link](https://github.blog/changelog/2026-11-18-gemini-4-neon-in-github-copilot)
- **GitHub Copilot:** Team customizations are generally available. A team maintainer can set approved Copilot plugins (add-ons that give Copilot extra tools) as defaults for the team's direct members; org policy still overrides. Business and Enterprise only. [link](https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team)
- **GitHub Copilot:** Copilot Fusion, a mode where Copilot picks the model for each task, now works on the web, in Visual Studio and in the mobile beta apps. GitHub reports 71.2% on Terminal-Bench 4.1, a test of hard terminal tasks; that is GitHub's own claim, which I did not verify. [link](https://github.blog/changelog/2026-11-17-github-copilot-fusion-updates-more-availability-benchmarks-and-models)
- **GitHub Copilot app:** Now works with Azure DevOps repositories (public preview), and can drive your signed-in Chromium browser (Chrome or Edge) through an extension. [link](https://github.blog/changelog/2026-11-17-github-copilot-app-microsoft-ignite-releases)
- **GitHub Copilot:** Connectors for eight more services (for example Supabase, Box, Calendly, ClickUp, Buildkite). A connector is a verified link that lets Copilot read and act in another service. Preview; a Business or Enterprise admin may need to allow them. [link](https://github.blog/changelog/2026-11-18-connect-supabase-box-calendly-and-more-to-copilot)
- **Simon Willison:** "External sandboxes for coding agents." A sandbox is a walled-off machine where an agent's commands run, so a mistake or a malicious prompt cannot reach your own computer. He released three open-source sandbox servers and says Claude Code can be pointed at them. I have not tried them. [link](https://simonwillison.net/2026/Nov/17/external-sandboxes-for-coding-agents/)
- **Forward Future (original essay):** Hands-on review of Claude Duet, Anthropic's assistant that looks for work before you ask. The reviewer found it caught a cancelled meeting and missed a few things, and sometimes took longer than doing the task by hand. Useful for deciding how much to hand it. [link](https://forwardfuture.com/newsletter/originals/claude-duet-wants-to-be-your-ai-chief-of-staff-i-put-it-to-the-test)
